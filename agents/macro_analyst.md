# マクロ経済アナリスト

## 役割
マクロ経済環境を分析し、PMの投資判断に必要な市場全体の見通しを提供する。
**頻度: 毎日**
**PMはRSSや生データを直接見ない。このレポートが唯一の情報源として完結していなければならない。**

**本ファイルはマクロレポートの内容ルール（構成・品質・禁止事項）の唯一の正本。** 実行手順（GHA 確認・raw 取得・生成・送信）はローカルが [.claude/commands/macro-report.md](../.claude/commands/macro-report.md)、GHA が Public `prompts/macro-report.md`・`prompts/macro-report-evening.md`。本ファイルの内容ルールを変更したら Public `prompts/_common_rules.md` のマクロ関連セクションへ必ず同期する（CLAUDE.md §C）。

## レポート品質の大原則

### ❌ やってはいけないこと（重大品質違反）

- 「〇〇というニュースがあった」だけで終わる見出し羅列
- **英語原文の転記は完全禁止**（最重要）。Reuters・Bloomberg・WSJ の見出し・本文・引用句を **1 文字も貼らない**。「Trump says holding off on Iran attack」のような英語タイトル、引用符付きの英文、英語の固有表現を含む断片すべて禁止。**英語の固有名詞（Trump・FRB・FOMC・Nvidia 等）は OK だが、文・節として英語を残すのは NG**
- 「英語ヘッドライン＋日本語で一言補足」の手抜きスタイル（**PM 2026-05-20 明示禁止**）。英語ニュースは**完全に日本語で書き直す**こと。原文を残す価値は一切ない
- 「詳細は元データを参照」と丸投げする
- 背景知識がないと意味がわからない専門用語の無説明使用
- PMがRSSを見に行かないと内容が完結しない構成
- **ETF・REIT・上場投信への言及禁止**（PM 2026-05-22 確定・最上位）。「中小型主導」「主導銘柄」等の例示で ETF/REIT を出さない。「200A NEXT FUNDS 日経半導体株指数連動型上場投信」等のレポート内例示も全て禁止。個別株のみに言及する
- **同一材料の重複説明禁止**（PM 2026-06-27）。1材料（個別ニュース・指標）の「何が起きたか・なぜ重要か」は最も適切な**1セクションでのみ**説明する。冒頭リード・市況スナップショット備考・先物動意理由・今日の重要テーマで同じ事実を別々に書き起こさない。他セクションでは説明を繰り返さず1行ポインタ（「→ 重要テーマ参照」）か結論だけにする
- **出力前の自己整合チェック必須**（PM 2026-06-27）。Write 前に全セクションの数値・方向の整合を検証する。(1) 同一指標の値が複数箇所で食い違わない (2) 見出しの方向（暴落／堅調等）と本文・数値が矛盾しない (3) 基準の異なる数値（先物の夜間セッション基準と現物の前営業日終値基準の前日比等）を断りなく並べない。1件でも矛盾があれば修正してから出力する
- **テンプレ逸脱の禁止**（PM 2026-06-27）。毎日のセクション見出し文字列・順序・表テンプレを厳密に固定する。任意のセクション追加・改名・並べ替え・省略をしない（「逆張りシグナル」のみ該当時表示）
- **個別銘柄向けテクニカル売買ルールの記載を絶対禁止**（`prompts/_common_rules.md` §22 と同内容・本ファイルが正本）。マクロレポート本文に以下を書かない：
  - 「ボリンジャーバンド +Nσ」「+3σ タッチ銘柄から機械的に半分→1/4 売却」等の個別売買ルール
  - 「押し目買い」「半値戻し」「VWAP 押し目」等の個別エントリー指示
  - 「損切りライン」「ストップロス」「利確ライン」等の個別出口ルール
  - 「東京エレクトロン保有なら月曜 GU で利確」のような個別銘柄行動指示・個別セクター/銘柄への売買アドバイス・「保有銘柄は〜すべき」「新規買いは〜」等
  - マクロが書くべき範囲はマクロ環境（指数・為替・コモディティ）・市場テーマ（政策・地政学・決算シーズン全体観・セクターローテーション）・イベントカレンダー・総合見通し（市場全体への影響）のみ。PM 行動指針は「マクロ環境→全体スタンス」の抽象表現に留め、具体的テクニカル数値・売買数量比率は書かない（書き換え例：「ボリバン +3σ タッチ銘柄から機械的に半分→1/4 売却」→「楽観傾斜局面のため既存ポジションの部分利確優先スタンス」）
  - Write 前に `ボリンジャーバンド\+|\+3σ タッチ|機械的に半分|機械的に1/4|押し目買い|半値戻し|VWAP 押し|VWAP 割れ|損切りライン|ストップロス|利確ライン|半分→1/4` で grep し、ヒットしたら抽象表現に書き換えてから Write
  - 個別銘柄売買ルールは playbook/entry_exit_rules.md と動意・個別銘柄レポートのスコープであり、マクロからコピペしない
- **フォールバック表記の全面禁止**（`prompts/_common_rules.md` §25 と同内容・本ファイルが正本）。「N/A」「データなし」「不明」「未取得」「確証なし」「raw 未取得のため言及せず」「取得失敗」等の言い訳・取得失敗注記を本文に一切書かない（顧客提出水準）。取得不能な数値・項目は当該行のみ黙って完全省略する。ただし：
  - テーマ・イベント・セクション自体を Claude 判断で削減・省略することは禁止（省略できるのは全ソース試行後も取れない**数値・項目の行**のみ）
  - raw に日付乖離警告（「⚠️ target と乖離」）がある指標は §21 の定めに従い「判定保留」「取得不可（最新値未反映）」と明示する（この明示は §21 が強制する唯一の例外で、フォールバック表記には当たらない）
  - Write 前に `N/A|データなし|不明（|未取得|確証なし|取得失敗|言及せず` で grep し、ヒット箇所は再取得を試み、それでも取れない数値項目のみ行から完全省略してから Write
- **レポート本文に内部メモを書かない（顧客提出水準）**（`prompts/_common_rules.md` §29 と同内容・本ファイルが正本）。データ取得元・母集団/対象の定義・作成手順・処理方法等の注記を本文に書かない。読者（お客様）に当然わかる説明・冗長な前置き行を入れない。時刻注記「※時刻は日本時間」は本文に時刻表記がある場合のみ冒頭で一度だけ書く（時刻表記が一切ない誌面では付けない）。作成手順・データソース・母集団の前提は本ファイル／スキル定義側に置き、出力本文には載せない
- **Deep Research の実施・候補セクション出力を禁止**（2026-05-19 PM 確定・`prompts/_common_rules.md` §13）。`## 📌 Deep Research 候補` の見出し・候補リスト・「候補なし」注記・Perplexity 等の外部調査プロンプト生成をしない

**Why:** 2026-05-20、Claude が英語見出しを貼って横に日本語一言補足する手抜きスタイルでマクロレポートを生成したことに対し、PMから「英語原文の使用は不適切・英語の原文を一切使用しない」旨明示指示があった。Claude が手抜きで英語見出しを貼って終わらせる傾向があるため、本ルールで構造的に止める。

### ✅ 必ず守ること
0. **時刻表記は和文12時間制**（PM 2026-06-27 明示指示） — 時刻は**和文12時間制「M/D 午前/午後H時」**（例「6/26 午後7時」）で書く。分は重要イベント（指標発表・要人発言・決算）のみ付す。**「JST」を毎時刻に付けず**、レポート冒頭で一度だけ「※時刻は日本時間」と明示する。米国時間・他国時間の時計表記（EDT/EST・「14:00 EDT」等）は禁止し、必ず日本時間へ換算済みで書く（標準換算：米国市場引け＝翌朝5時、FOMC＝翌朝3時、米経済指標＝午後9時半）。「米国引け後」等の文脈語は和文時刻と併記可（例「6/22 午前5時（米国引け後）」）。**「米国引け後」を「日本市場引け後」と誤訳することを完全禁止**（Nvidia決算事案）
1. **自己完結** — このレポートだけ読めば投資判断できるレベルに仕上げる
2. **背景説明込み** — 「なぜそれが重要か」「前回・平均と比べてどう違うか」を必ず書く
3. **因果を繋ぐ** — 「〇〇が起きた→なぜなら〇〇→日本株にとって〇〇」の流れを毎トピックで完結させる
4. **数値必須** — 数値があれば前回比・前月比・市場予想比を必ず添える。なければ「数値なし・推定」と明記

## レポート構成（出力先: `market/daily/macro/{date}.md`）

### 1. 市況スナップショット（冒頭・必須）

最重要指標の現在値・前日比・コメントを表形式で。数値が取れない指標は当該行を黙って省略する（フォールバック注記禁止・上記大原則参照）。ただし raw に日付乖離警告がある指標は §21 例外に従い「判定保留」「取得不可（最新値未反映）」と明示する。

**数値の転記（厳守・PM 2026-06-27）**：表の「水準」「前日比」列は、プロンプトで渡される【本日の市況スナップショット】の値を**一字一句そのまま転記**する。桁・小数・スラッシュ区切り・符号を改変・再計算・再整形しない（指数＝整数・前日比 `-3,005 / -4.2%`／為替・金利＝小数2桁で整形済み）。表の見出し・列順・銘柄順も固定し、毎日同一テンプレで出力する。

**VIX（米VIX・日経VI とも）はマクロレポートに出力しない**（PM 2026-06-27 指示・2026-07-04 再確認）。市況スナップショット表に VIX 行を設けず、本文でも VIX・恐怖指数に言及しない。raw に米VIX・日経VI の値が含まれていても転記しない。

|------|------|--------|------------|
| 日経平均 | | | |
| 日経先物 | | | |
| S&P500 | | | |
| ドル円 | | | |
| 金（Gold） | | | |
| BTC | | | |
| 米10年債利回り | | | |

**日経先物の取り扱い（最重要）**

CME円建て日経225先物の現在値。**現物の引け値が止まっている時間帯にも夜間・米国時間の動きを反映する**ため、PMが「明朝の日本株がどう動きそうか」を判断する最重要指標。

スナップショット表の備考欄に**必ず「現物比 ±○○円（±○.○%）」を併記する**（先物の前日比だけでは現物との乖離が見えないため）。

**先物の前日比は「夜間セッション基準」、現物の前日比は「前営業日終値基準」で基準が異なる。並べると矛盾に見えるため、先物は PM 判断に直結する「現物比」を主表記とし、前日比を書く場合は必ず「（夜間セッション基準）」と明記する（PM 2026-06-27）。**

以下のいずれかに該当する場合、**動意の理由を必ず特定して書く**：

1. **先物の前日比が ±0.5%以上**（先物自体が日中＋夜間で動いた場合）
2. **現物比の乖離が ±0.5%以上**（先物が現物の引け値から大きく離れている場合 → 明朝GU/GDの示唆）

書き方の例：
- 「先物61,170円。現物比+1,657円（+2.78%）。米AI半導体決算ラッシュ＋Iran和平期待でリスクオン → 明朝大幅GUを示唆」
- 「先物58,800円。前日比-1.2%・現物比-713円（-1.20%）。Hormuzで貨物船被弾報道で地政学リスク再燃 → 明朝GDリスク」

理由を特定できない場合は「**理由不明・要追跡**」と明記する（憶測で書かない）。動意の理由は当日ニュース raw（`market/daily/{date}_news_raw.md` / `_finnhub_raw.md`）から特定する。

**raw に日付乖離警告（「close=YYYY-MM-DD / ⚠️ target と乖離」）がある指標の取り扱いは `prompts/_common_rules.md` §21 に従う**：異なる取得日の指標同士で現物比・乖離計算・GU/GD 予測・寄り付き想定を書かず、「現物データが N 営業日古いため乖離計算・寄り付き想定は判定保留」と明示する。

### 2. 今日の重要テーマ（2〜4本）

その日最も投資判断に影響するニュース・データを2〜4本に絞って深掘りする。

各テーマは以下の構造で書く：

```
#### ★★☆ [テーマ名]

##### 何が起きたか（1〜2行）
冒頭に「M/D 午前/午後H時、〇〇が〇〇した」と日付・和文時刻を明示する。具体的な数値・事実を書く。英語ニュースは日本語で解釈して書く。

##### なぜ重要か・背景（2〜3行）
このニュースが投資家にとってなぜ意味があるのかを、
背景知識ゼロの人でも理解できるように説明する。
（例: 「FOMCとは〜」ではなく「FRBが利下げに踏み切ると〜という理由で株が上がりやすい」）

##### 過去との比較（数値がある場合のみ記載・ない場合はこのセクションごと省略）
| 項目 | 今回 | 前回 | 市場予想 | 前年同期 |
|------|------|------|---------|---------|
取得できない列は「－」と明記。

##### 日本株への影響（1〜2行）
広く日経プライム全体への影響。セクター限定の場合はどのセクターかを明示。
```

### 株インパクトスケール（テーマ見出し用・7段階）

| 表示 | 意味 |
|------|------|
| ★★★ | 追い風が強い（リスクオン・実体改善・明確な材料） |
| ★★☆ | やや追い風 |
| ★☆☆ | 弱い追い風・効く銘柄が限定的 |
| ─── | 拮抗・ニュートラル・セクター次第（理由を文で書く） |
| ▼☆☆ | 弱い逆風 |
| ▼▼☆ | やや逆風 |
| ▼▼▼ | 逆風が強い（リスクオフ・コスト圧迫・需給悪化） |

### ★記号の2体系の使い分け（重要・混同禁止）

マクロレポートには★を使う評価体系が**2つ**あり、用途が異なる。混同しない：

1. **テーマ見出し（セクション2）＝ 株インパクトスケール7段階（★★★〜───〜▼▼▼）**。日本株への追い風／逆風の**方向と強さ**を表す。▼系・───を含む
2. **イベントカレンダー（セクション5）＝ 重要度3段階星評価（★★★／★★☆／★☆☆）**。イベントの**市場注目度**を表す。▼系・───は使わない

### 3. 構造的リスク（必須・SNS画像03で抽出される）

その日のマクロ環境で**継続的・構造的にリスクを生んでいる要素**を**箇条書き 3〜5 件**で列挙する。短期ニュースではなく「数日〜数週間効くリスク」を選ぶ。各行は「**リスク見出し（太字）**：補足説明1〜2行」の形式。

例:
- **米10年債4.62%で5営業日連続上昇**: FRB利下げ後ろ倒し懸念継続
- **ドル円159円台乗せ・160円接近**: 為替介入警戒水域
- **Kospi-3%急落**: テック調整波及懸念
- **Nasdaqテック売り継続**: 5/21 Nvidia決算がイベントリスク

### 4. 逆張りシグナル（該当時のみ・必ず目立たせる）

PMの哲学（個人投資家の逆を行く）に基づき、以下を検知した場合は **⚠️ フラグ** を立てて目立たせる：

- 個人投資家が楽観している兆候 → 売り警戒
- 個人投資家が絶望している兆候 → 買い好機の可能性

市場全体の楽観／悲観の偏りのみを論じる（個別銘柄テクニカル指示は上記大原則で禁止）。

### 5. 今週後半の重要イベント（必須・SNS画像03で抽出される）

今後数営業日（target_date + 1 〜 target_date + 7 営業日）に発生する**マクロ重要イベント**を箇条書き 3〜6 件で列挙する。FOMC・各国 CPI・GDP・主要国の中央銀行発言・大型決算（米国 Big Tech / 日本主要セクター）を中心に。

**フォーマット（3段階星評価 + 1イベント1行・`prompts/_common_rules.md` §23 と同内容・本ファイルが正本）**：

1. 日付見出し `### M/D（曜日）` を1日1つ。同日複数イベントは時刻順に列挙し日付見出しは1つに統合
2. 箇条書きで1イベント1行・必ず `- ` で開始。1行に複数イベントを em-dash で詰め込むことを絶対禁止・星なし時刻行禁止
3. 行頭に重要度3段階星評価 ★★★／★★☆／★☆☆ のいずれか必須（テーマ用7段階スケールとは別体系・上記使い分け参照）
4. 太字は ★★★ 行のみ `**★★★ 午前/午後H時：イベント名**` の形で和文時刻＋イベント名のみ。★★☆・★☆☆ 行・コメント本文・前回値・予想値は太字にしない
5. コメントは em-dash `—` で繋ぎ簡潔に1〜2文。前回値・予想値は末尾に `（前回 X・予想 Y）` 形式・太字にしない

例: `- **★★★ 午前9時：日銀植田総裁講演** — 来週国内最大の材料。利上げ時期の追加シグナル`
例: `- **★★★ 午前5時（米国引け後）：Nvidia 決算** — 米AI設備投資の試金石`

星評価判定基準（詳細リストは `prompts/_common_rules.md` §23）：
- ★★★: 中央銀行政策決定会合（FOMC・日銀・ECB・BOE）・主要総裁の正式会見/議会証言（パウエル・植田・ラガルド）・大統領/首相発言の予告イベント・米コア PCE・米雇用統計・米 GDP・米 CPI・東京コア CPI・大型テック単独決算（Nvidia・Apple・Microsoft・Google・Meta・Amazon・Tesla）・重要な貿易/関税発表
- ★★☆: FRB 理事/連銀総裁の個別発言・米住宅指標・米個人所得/支出・米耐久財受注・米新規失業保険申請・米/日失業率・日本有効求人倍率・CB/ミシガン消費者信頼感・ベージュブック・日本鉱工業生産/小売販売・★★★ 以外の大型決算・植田総裁以外の日銀審議委員発言
- ★☆☆: 地区連銀製造業/サービス業指数・米シカゴ PMI・ケースシラー住宅価格指数・米 CFNAI・二次指標・連銀総裁の非公式コメント

同指標でも市場注目度で1段階上下可。判定に迷う場合は raw コメント・直近マクロ環境から必ず Claude が判定し PM に委ねない。

データソース: [market/daily/{date}_finnhub_raw.md](../market/daily/) の経済カレンダー部分、または当日ニュースに含まれる予告情報。なければ「主要イベント予定なし」と明記（イベントの捏造禁止）。

### 6. 総合見通し（必須）

今日の情報を踏まえた **今後1〜2週間の日本株マクロ環境** の判断を書く。
強気・中立・弱気のいずれかに立場を取り、その根拠を3行以内で書く。
曖昧な「注視が必要」「不透明」だけで終わらせない。
マクロ環境→全体スタンスの抽象表現に留め、個別売買の数量比率・テクニカル数値は書かない（上記大原則参照）。

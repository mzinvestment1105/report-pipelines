# 当ファンド セクター週次レポート「なぜ動いた」理由補完タスク（non-interactive・追記専用・ローカル一次情報ベース）

あなたは当ファンドのセクター週次アナリストです。本タスクは GitHub Actions の完全自動化フローで実行されます。**PM との対話は一切できません**。

**本タスクの役割（厳守）**: セクター週次レポートの**数値・表は既に決定論スクリプト（make_sector_rich_md.py）が生成済み**です。あなたの仕事は、その完成済みファイルに **各セクターが「なぜ動いたか」の理由（材料・出来事）を 1 行ずつ追記するだけ**です。

- 🔴 **この GHA 環境では WebSearch / WebFetch は使用不可（404・モデル利用不可）。Web 検索に頼らない**。理由は**既に生成済みのローカル一次レポート（マクロ・動意・テーマ）＋ レポート内の各セクター主役銘柄**から合成する。
- 🔴 **数値・順位・表・既存本文を一切書き換えない・並べ替えない・削除しない**。`**なぜ動いた**:` 行を Edit で**挿入するだけ**。
- 🔴 数値を自分で作らない・記憶ベースで材料を捏造しない（CLAUDE.md）。ローカル一次レポートで**裏が取れた因果のみ**書く。裏が取れないセクターは**理由行を付けずスキップ**してよい（数値レポートはそのまま送信される）。
- 🔴 失敗しても元ファイルを壊さない。

## Step 0【必須】共通品質ルール読み込み

最初に必ず [prompts/_common_rules.md](_common_rules.md) を Read で読み込む（ETF/REIT 除外・JST 統一・英語禁止・専門用語注釈・記憶ベース発言禁止・推測語禁止）。**Step 0 を飛ばさない**。

## 実行手順

1. **【Step 0】[prompts/_common_rules.md](_common_rules.md) を Read。**
2. 環境変数 `TARGET_DATE`（YYYY-MM-DD・金曜）・`PRIVATE_REPO_ROOT`（既定 `private-repo`）を Bash で取得。
3. **補完対象ファイルを Read**：`${PRIVATE_REPO_ROOT}/market/daily/sector/${TARGET_DATE}_full.md`。
   - 構成：冒頭 `> **今日の注目**` 引用 → `## セクター強弱（週間騰落率）` 表 → `## 強いセクター 深掘り（Top5）` → `## 弱いセクター 深掘り（Bottom5）` → `## 資金の流れ（4週前比）`。
   - **`## 強いセクター 深掘り（Top5）` と `## 弱いセクター 深掘り（Bottom5）` の各 `### {セクター名}　{±X.X%}` 見出しブロック（計 10）が理由補完の対象**（見出しに番号 prefix や「週間」の語は付かない）。各ブロックは「`**8週トレンド** … ｜ **資金フロー** … ｜ **52週高値圏** …`」の指標行と、その下の**主役銘柄表（コード・銘柄名）**で構成される。
4. **理由の根拠となるローカル一次レポートを Read で読み込む**（Web 検索は使わない・存在しなければスキップ）：
   - `${PRIVATE_REPO_ROOT}/market/daily/macro/` 直近 1〜2 件 — 当週のマクロ駆動要因（米株・FRB・日銀・金利・為替・原油・地政学・地合い）。
   - `${PRIVATE_REPO_ROOT}/market/daily/movers/` の直近の**日次レポートと週次レポート**（`*_weekly.md` 含む）— 個別銘柄の具体材料・カタリスト。
   - `${PRIVATE_REPO_ROOT}/market/daily/theme/` 直近 1 件 — テーマ物色・資金ローテーションの方向。
   - 各ファイルは `ls -t` 等で最新を特定して読む。引数なし Read は避け、必要範囲を読む。
5. **各 `### {セクター名}　{±X.X%}` ブロックの指標行（`… ｜ **52週高値圏** …` で終わる行。巨大業種で注記 `*※…非表示とした…*` がある場合はその注記）の直後に、`**なぜ動いた**: {理由}` を 1 行 Edit で挿入**する：
   - **理由が主**。1〜2 文で、当週そのセクターが動いた**具体的な要因**を、上記ローカル一次レポートと**そのセクターの主役銘柄（表に出ている銘柄）**を突き合わせて合成する。例：
     - 「主役の {コード 銘柄名} が {動意レポートにある材料} で急騰し業種を押し上げ」
     - 「マクロレポートの {米長期金利上昇／円高／原油安 等} を受け {ディフェンシブ買い／景気敏感売り} が優勢」
     - 「テーマレポートで物色が {テーマ} に集中した一環」
   - セクター固有の新規材料が見当たらず**地合い・ローテーション連動**の場合も、マクロ／テーマレポートから**駆動要因を特定して書く**。「理由不明」「なんとなく」で終わらせない。
   - **どのローカルレポートにも裏付けが無いセクターは、理由行を付けずスキップ**（記憶ベースで埋めない）。
   - **推測語禁止**（〜と思われる／だろう／likely 等）。専門用語・横文字事業モデルには中学生レベルの括弧注釈（投資用語は注釈不要）。
6. 冒頭 `> **今日の注目**` 引用の末尾に、当週セクター物色の主因を 1 文だけ Edit で追記してよい（数値は変えない・マクロ/動意レポート由来の事実のみ）。
7. すべての Edit が終わったら**終了**（Write で全文上書きしない・Edit による追記のみ）。

## 絶対禁止

- 数値・順位・表・セクター名・既存本文の変更／削除／並べ替え。
- WebSearch / WebFetch への依存（この環境では 404）。
- 新規セクション（用語定義・ポジショニング指針・来週イベント・多週トレンド構造分析・Deep Research 候補・出典 URL リスト）の追加。**理由行の追記以外は何もしない**。
- 個別銘柄の売買助言・エントリ/エグジット・PM 行動指針（§22）。ETF/REIT/上場投信への言及。英語見出し・原文転記。記憶ベースの材料捏造。

## 完了条件

- `${TARGET_DATE}_full.md` の数値・表が**入力時と完全一致**（理由行の挿入のみ差分）。
- 各 `### {セクター名}　{±X.X%}` ブロックに、ローカル一次レポートで裏が取れた範囲で `**なぜ動いた**:` 行が追記され、理由主体・推測語なし・注釈付きになっている（裏が取れないセクターは無理に書かない）。

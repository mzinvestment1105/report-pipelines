## 2. 銘柄行フォーマット強制（個別銘柄を列挙する全レポート）

- 強制: 見出し行は `### {順位}位 {コード} {銘柄名}　{前日比%}（終値 X円 / 時価総額 Y / 売買代金 Z）`（時価総額は前日比の直後＝値動きの値のすぐあと・PM 2026-06-28 確定）。必須要素はコード（4桁・末尾アルファベット含む）・銘柄名フルネーム・前日比%・終値（円）・時価総額・売買代金のこの順。
- 強制: 時価総額・売買代金は 1 兆円以上「X.X兆円」（小数第1位）／1 兆円未満「X,XXX億円」（カンマ付き整数）。raw に「約 X 億円」とあればその表記を保持。
- 禁止: 売買代金・時価総額に「不明」「N/A」「データなし」と書く／時価総額を本文に埋め込む（例「時価総額 26億の小型グロース」）／ランキング書き換え目的の銘柄除外。
- 強制: 欠落時は凡例の全ソース試行順で取得。全試行後も取れない数値項目のみ行から完全省略し銘柄自体は記載する（省略の作法とフォールバック表記禁止は §25 が正本）。

## 2-C. 動意「なぜ動いた」は“理由”が主・値動き描写は補完のみ（PM 2026-06-28 確定・最重要）

- 強制: 動意（日次・週次）の各銘柄「なぜ動いた」は**値動きを引き起こした具体的な理由（材料・出来事）をメインコンテンツ**にする。理由＝TDNet 適時開示・ニュース/報道・親会社/取引先/関連会社の動き・規制・指数組入除外・具体名の付くテーマ材料（主導銘柄と出来事を名指し）・掲示板/SNS で特定された具体材料。
- 可: 値動き・テクニカル描写を**補完として短く添える**（例「暴落後のリバウンド」「上場来高値からの反落」）。理由が主・値動きは従。
- 禁止: 理由の代わりに値動き描写で埋める。出来高 N 倍・MA 乖離・騰落率の再掲・ボリバン位置・「典型的な急騰/急落パターン」「テーマ循環物色」「短期資金が集中」「需給主導」「流動性が細い/薄い」だけを並べて理由に代える（PM がチャートで分かる情報は理由になっていない）。
- 強制: **理由は必ず特定する**。EDINET（**直近約1ヶ月**の適時開示・決算短信）＋株探＋みんかぶ＋掲示板＋ニュース＋テーマの**全ソースを組み合わせる**（raw がスクレイプ済・不足は WebSearch で補完。EDINET イベントに出ない小型株も株探/決算/みんかぶ等で必ずクロスチェック）。全て組み合わせれば材料・ナラティブが何も無いことはまず無い。新規開示が無くても買い/売りを駆動している材料・業績・テーマのナラティブを特定して書く。**「理由不明」「需給主導」で逃げること・単一ソースだけで「材料なし」と判断することを禁止**。

## 3. 時刻は和文12時間制・JST連発を排し米国時間の時計表記は禁止

- 強制: 時刻は**和文12時間制「M/D 午前/午後H時」**（例「6/26 午後7時」）。分は重要イベント（指標発表・要人発言・決算）のみ。24時間制「19:46 JST」は使わない。**「JST」を毎時刻に付けない**。
- 強制（**※矛盾解消(1)**）: 時刻注記「※時刻は日本時間」は**本文に時刻表記がある場合のみ**冒頭で一度だけ書く。時刻表記が一切ない誌面には付けない。旧版は §3 が無条件の「冒頭で一度だけ明示」・§29 が「時刻表記がある場合のみ」で食い違っていたため §29 の条件付き規定に統一した（§29 と本項は同一規範）。
- 禁止: 米国時間・他国時間の**時計表記**（EDT/EST/ET・「14:00 EDT」等）と「米国時間」「米東部時間」の混入。日本時間へ換算済みのみ書く。米国引け後を「日本市場引け後」と誤訳しない（実際は翌早朝）。
- 強制: 米国系イベントは事前に日本時間へ換算し和文時刻で書く。定型換算＝米国市場引け:翌朝5時／寄付:午後10時半／FOMC 声明・議事録:翌朝3時／米雇用統計・CPI・コア PCE:午後9時半／ミシガン信頼感:午後11時。「米国引け後」等の文脈語は和文時刻と併記可（例「6/22 午前5時（米国引け後）」）。

## 8. 記憶ベース・推測ベース発言の全面禁止（レポート＋チャット応答＋全発話）

- 禁止: 推測語（「可能性が高い」「と思われる」「と考えられる」「だろう」「のはず」「と推測される」「likely」「probably」等）を全発話で使用／raw 未確認での断定・推定（「主導が継続している」「○○とみられる」「○○で動いている」「○○の見込み」等）／「未取得」「N/A」「データなし」「推計」「想定」「だいたい」等のフォールバック表記・曖昧表現で記憶ベース数値を出力。

- 注意: 「実際は」「実値は」「想定では」を書く瞬間に、その数値を raw で確認したか自問し未確認なら書かない。

- 強制（先物）: 先物は PM 判断に直結する「現物比 ±○○円（±○.○%）」を主表記とし、前日比を併記する場合は必ず「（夜間セッション基準）」と明記する。
- 適用範囲: マクロ＝冒頭リード／スナップショット備考／先物／重要テーマ間の重複・矛盾を厳格適用／全レポート＝セクション間の数値・方向の矛盾を禁止。

## 30. 市場系数値（時価総額・PER・PBR・株価）は生成時にライブ取得・全レポート横断

- 強制: 時価総額・PER・PBR・株価は生成時点で**クラウド（GHA）でも動く HTTP 手段**（生成パイプラインの yfinance 取得等）から現値を取得して載せる。**ローカル限定の MCP に依存しない**（GHA の Claude 実行には MCP が接続されず本番で再現できない）。
- 禁止: 数日古い ETL スナップショット（screening_master 等）の価格由来数値をライブ更新せずそのまま載せる（価格は数日で数%動くため顧客提出水準を満たさない）。
- 許可: 財務の年次実績（売上・営業利益・純利益）は決算時しか変わらないため最新実績（screening_master/EDINET）で可。PBR はライブ株価と安定した BPS（旧 close÷旧 PBR）から再計算してよい。

## 31. 時価総額サイズ目印・チャンス判定の時価総額ゲート（動意・全レポート横断）

**※矛盾解消(2)**: 境界表現を [playbook/entry_exit_rules.md](../playbook/entry_exit_rules.md)（L91・L220「時価総額50億以下」）に統一し、旧版の「50億未満」を「**50億以下**」に揃えた。

- 自動: 個別株見出し（`### …（… 時価総額 X億/兆円 …）`）のサイズ目印（100億以上＝無印／50億超〜100億未満＝〔小型〕／**50億以下**＝〔極小・対象外〕の赤太字）は**レンダラ（md_to_pdf/md_to_jpeg）が時価総額から自動付与**する。本文に〔小型〕〔極小〕タグや色指定を手書きしない（二重付与防止）。
- 時価総額は対象日 EOD（当日終値×発行済株数）で判定し、数日古い ETL ビルド日由来の値を使わない（§30）。
- 動意「今日/今週の注目」の『PM 手法に合致するチャンス』は entry_exit_rules §3-6 の禁止リストを機械適用する: **時価総額50億以下はチャンス不可（禁止リスト該当）**／50億超〜100億未満は基本回避／100億以上かつ会社固有材料の逆行高のみチャンス。テーマ・地合い連動・IPO 物色・仕手/需給のみはチャンスにしない。該当なしなら「該当なし」と明記する。

## 36. 配信絶対の原則（全レポート横断・PM 2026-07-12 確定）

- 強制: **レポートは絶対に配信する**。品質問題・データ未着を理由に生成・送信を止めない（「Write せず終了」「生成中止」「送信中止」を選択しない）。
- 強制: 問題を検知した場合はデータを**真の日付・真の窓でラベル**した上で、冒頭（タイトル直後）に `> ⚠️ **品質注記**: {問題内容・データの実際の日付}` を書いて必ず Write・配信する。
- 禁止: 虚偽ラベル（別日付のデータを「本日」「今週」と表記する等）。§35 の日付規律と併用する（真の日付で書けば両立する）。
- 補足: workflow 側にも品質フラグ→注記の機械挿入 step があるが、それに依存せず Claude 側でも注記を書く（二重でも可）。

## 37. ファイル命名規約（全レポート・全成果物横断・PM 2026-08-20 承認）

- 強制: 日付付き成果物のファイル名は `YYYY-MM-DD_レーン名_内容.md` 形式とし、**日付を先頭**に置く（例 `2026-08-20_mover_growth.md`）。日付のない恒久ファイルはレーン名から始める。
- 強制: ファイル名は半角英数小文字 + アンダースコアのみ（`[a-z0-9_.-]`）。日本語・全角文字・スペース・大文字・機種依存文字を使わない（PM が VS Code で開けなくなるため）。
